# MATLAB Student Resources

A practical reference for students learning MATLAB. This repository is organized for quick lookup as well as deliberate practice.

| Section | What it contains |
|---|---|
| `cheat-sheets` | Compact syntax references |
| `common-commands` | Frequently used commands with examples |
| `practice-problems` | Problems grouped by difficulty |
| `debugging-tips` | A repeatable debugging workflow |
| `matrix-operations` | Indexing, algebra, and decompositions |
| `plotting-guide` | Plot construction and presentation checklist |
| `numerical-methods` | Root finding, integration, and derivatives |
| `documentation` | Official documentation and learning links |

This is a learning resource, not a marketing page. Every section should answer a concrete student question and include a runnable example or a clear exercise.

## Cheat sheets

- [Core Syntax](cheat-sheets/core-syntax.md): vectors, indexing, operators, functions, and plots.
- [Arrays and Matrices](cheat-sheets/arrays-and-matrices.md): construction, indexing, reshaping, concatenation, and matrix operations.
- [Control Flow and Functions](cheat-sheets/control-flow-and-functions.md): conditions, loops, functions, assertions, and error handling.
- [Plotting and Data](cheat-sheets/plotting-and-data.md): figures, chart types, tables, file import, and export.

## Common commands

- [Common MATLAB Commands Reference](common-commands/reference.md): workspace, statistics, linear algebra, numerical methods, signal processing, image processing, and profiling.

## Suggested workflow

Use the cheat sheets while solving a practice problem, consult the debugging guide when a result looks wrong, and compare your implementation with the worked examples in [MATLAB Programming Examples](https://github.com/brianmills-code/matlab-programming-examples).
